# とち介商品券2026 マップ 動作環境

**利用者の端末に何が必要か**をまとめたもの。市民から「見られない」と言われたときの
切り分けにも使う。

サーバー側の条件は `doc/サーバー要件.md`、日々の更新手順は `doc/運用手順.md`。

---

## 1. まとめ

| | 必要なもの |
| --- | --- |
| **iPhone** | **iOS 12 以上**（一覧・検索）／ iOS 14.5 以上（見た目が崩れない）／ **地図は最新 2 世代の iOS** |
| **Android** | **Chrome 64 以上**（一覧・検索）／ Chrome 84 以上（見た目）／ **地図は最新の Chrome** |
| **PC** | Chrome・Edge・Firefox・Safari。**地図は最新 2 バージョン**が条件 |
| 共通 | **JavaScript が有効**であること。**現在地を使うなら HTTPS**（公開 URL なら満たしている） |

**普段使っている端末なら、まず問題になるのは地図タブだけ。**
一覧と検索は 2018 年頃の端末まで動く。

---

## 2. 層ごとの下限

**機能ごとに必要な新しさが違う。** 低い方から順に、動かなくなるものが増える。

| 層 | 下限 | 下回ると何が起きるか |
| --- | --- | --- |
| **JS が動く（＝画面が出る）** | iOS 12 / Chrome 64 | **何も表示されない。** 代わりに非対応の知らせが出る |
| **見た目が崩れない** | iOS 14.5 / Chrome 84 | 動くが、ボタンやカードの隙間が詰まって窮屈に見える |
| ヘッダーの追従・暗い配色 | iOS 13 | スクロールしても検索窓が残らない。暗い配色に切り替わらない |
| **地図タブ** | iOS は最新とその 1 つ前のメジャー／Android は最新の Chrome | 地図が出ない（**一覧は使える**） |
| **現在地（近い順）** | HTTPS ＋ 位置情報の許可 | 押しても現在地が取れず、理由が表示される |

下限の根拠は次のとおり（いずれも実測）。

- **JS**: 配信しているコードに必要なのは最大 ES2018（オブジェクトスプレッド `{...a, ...b}`）。
  Safari は 11.1 から対応。実行時 API（`Object.hasOwn` など）は補完コードを同梱している。
- **見た目**: flexbox の `gap` を使っている。Safari は 14.1（iOS 14.5）から、Chrome は 84 から。
- **地図**: Google Maps JavaScript API 自体のサポート方針。Google が
  「iOS は現行とその 1 つ前のメジャー」「Android は現行の Chrome」と定めている。

## 3. スマートフォン

### iPhone / iPad

- **iOS 12 以上**で一覧・検索・絞り込みが使える。
- **iOS 14.5 以上**なら見た目も設計どおり。
- **地図タブは新しい iOS が必要**（Google の方針。2026 年時点で概ね直近 2 メジャー）。
  地図が出なくても一覧は使えるので、券が使える店は探せる。

**iPhone に Chrome や Firefox を入れても、対応する OS の下限は変わらない。**
iOS 上のブラウザは中身が全て iOS 同梱のエンジン（WKWebView）を使う決まりで、
「Chrome 71」と表示されていても動きは古い Safari と同じになる。
**端末が古い場合、解決策は iOS の更新か端末の買い替えしかない。**

### Android

- **Chrome 64 以上**で一覧・検索が使える。Chrome は OS と別に更新されるため、
  Android のバージョンが古くても Chrome が新しければ動くことが多い。
- **地図タブは最新の Chrome が条件。**
- 端末付属の「ブラウザ」アプリ（古い WebView ベース）では動かないことがある。
  その場合は Chrome で開いてもらう。

---

## 4. PC

- **Chrome・Edge・Firefox・Safari** のいずれか。一覧・検索は 2018 年頃のバージョンまで動く。
- **地図は最新 2 バージョンが条件**（Google の方針。Edge は現行のみ、IE モードは対象外）。
- **Internet Explorer は非対応**（Google Maps 側が 2022 年 11 月にサポートを終了している）。
- 画面が広いときは、業種・地区の絞り込みが**折り返して全部表示**される
  （スマートフォンでは横スクロール）。マウス環境では横スクロールが操作しづらいため。
- 本文は最大 720px 幅で中央に表示される。

## 5. 機能ごとに必要な条件

| 機能 | 条件 |
| --- | --- |
| 店名・住所・かなでの検索 | JS が動くこと。通信は初回のデータ取得（155 KB / 転送時 31 KB）だけ |
| 券種・業種・地区の絞り込み | 同上。**すべて端末内で処理する**ので通信は発生しない |
| 地図タブ | 上記の新しいブラウザ。地図を開いたときだけ通信が発生する |
| 現在地から近い順 | **HTTPS** と**位置情報の許可**。ボタンを押したときだけ許可を求める |
| 電話をかける | `tel:` を扱えること（スマートフォンなら標準） |

**地図を開かない限り、地図関連の通信は発生しない。** 一覧だけ使う利用者に
余計なデータ通信を負わせない設計にしてある。

## 6. 対応外の端末では何が出るか

古すぎるブラウザでは、5 秒ほど後に画面の文言が次に変わる。

> お使いのブラウザでは表示できません。iPhone は iOS 12 以上、Android は Chrome 84 以上で
> お試しください。地図の表示にはさらに新しい端末が必要です。

**これはアプリの不具合ではなく端末が対応外という意味。**
実際に iOS 10.3.4 の iPhone 5c で「読み込み中…」のまま止まる報告があり、
何も起きない画面が最悪なので、理由を出すようにした。

地図タブだけが対応外の場合は、地図の場所にその旨が表示される（最大 15 秒待って判定する）。
**一覧はそのまま使える。**

## 7. 「見られない」と言われたときの切り分け

| 症状 | 疑うところ |
| --- | --- |
| 「お使いのブラウザでは…」と出る | 端末が対応外。iOS か Chrome の更新を案内する |
| 「読み込み中…」のまま何分も止まる | 端末が古い、または**転送漏れ**（`_next/` を上げ忘れていないか） |
| 真っ白 | 転送漏れ。`_next/` 配下を一式上げ直す |
| 画面は出るが**地図タブだけ**空・エラー | 端末が Google Maps の対象外。または API キーのリファラー制限 |
| ボタンの隙間が詰まって見える | iOS 14.5 未満・Chrome 84 未満。動作に支障は無い |
| 「近い順」を押しても並び替わらない | 位置情報の許可。理由が画面に出ているはず |
| 更新した内容が反映されない | ブラウザキャッシュ。`shops.json` を転送したか |

## 8. なぜ下限を下げないか

**下げようとしたが、実際にやってみて割に合わないと判断した。**

ビルド設定を変えると構文の下限は 2015 年相当まで下がる（実験して確認済み）。
しかし Next.js のランタイム内部で `AbortController`（Safari 11.1 から）が
無防備に使われているため、それだけでは動かない。さらに地図は Google 側の方針で
原理的に動かせない。

**2013 年の端末のために、いま使っている全利用者の通信量を増やす取引になる。**
代わりに、対応外の端末には「なぜ見えないか」を表示する方を選んだ。
